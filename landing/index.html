p5.js → Lottie

Code your animation.
Ship it as a Lottie, not a GIF.

p5js-to-lottie records a running p5.js sketch — shapes, curves, text, images, gradients, translate/rotate/scale — and re-encodes it as a compact, vector, infinitely-scalable Lottie file instead of a bulky raster GIF.

See examples View on GitHub
01 · Simple

Transforms

A spinning square, an orbiting circle and a pulsing square — translate(), rotate(), scale() and push()/pop() baked into Lottie transforms.

02 · Intermediate

Curves & arcs

bezier(), Catmull-Rom curve(), arc() in its CHORD / PIE / default modes, a curveVertex() blob and a bezierVertex() + quadraticVertex() leaf, all animated.

Solar system

Seven planets on nested transforms, gradient-shaded spheres, Saturn's arc() rings, a quadraticVertex() comet with a fading gradient tail, text() labels and an image() starfield.

Get started

<!-- after loading p5.js -->
<script src="https://cdn.jsdelivr.net/npm/p5js-to-lottie@latest/dist/bundle.js"></script>

// sketch.js
function draw() {
  push();
  translate(width / 2, height / 2);
  rotate(frameCount * 0.05);
  fill(245, 10, 20);
  rect(-30, -30, 60, 60);
  pop();
}

// capture 4 seconds: `animation` is the Lottie JSON, `file` a ready-to-save Blob
saveLottie(4, (animation, file) => {
  document.querySelector("lottie-player").load(JSON.stringify(animation));
}, {
  minify: true,          // default: no spaces or line endings
  format: "dotlottie",  // or "json" (default)
});
Built on top of p5.js and lottie-web. See the example/ folder in this repo for more focused, single-shape demos.
